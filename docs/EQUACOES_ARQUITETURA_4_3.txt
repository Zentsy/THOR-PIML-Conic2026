1. Concatenação do Vetor Sinótico 2D com a Superfície 1D (Módulo 3):
- LaTeX: [1D \parallel Z_{syn}] \to (30, 148)
- Texto puro: [1D || Z_syn] -> (30, 148)

2. Fusão Adaptativa por Portão (Módulo 4):
- LaTeX: h_{fused} = g \odot h_{lstm} + (1 - g) \odot h_{tcn}
- Texto puro: h_fused = g ⊙ h_lstm + (1 - g) ⊙ h_tcn

3. Cabeça de Ocorrência Hurdle (Módulo 5):
- LaTeX: p_{occ} = \sigma(W_{occ} h_T + b_{occ}) \in [0, 1]
- Texto puro: p_occ = Sigmoid(MLP_occ(h_T)) em [0, 1]

4. Cabeça de Intensidade Hurdle (Módulo 5):
- LaTeX: \mu_{int} = \text{Softplus}(W_{int} h_T + b_{int}) \ge 0
- Texto puro: mu_int = Softplus(MLP_int(h_T)) >= 0

5. Precipitação Diária Final Contínua (Módulo 5):
- LaTeX: \hat{y} = p_{occ} \times \mu_{int}
- Texto puro: y_hat = p_occ × mu_int

6. Barreira Termodinâmica de Clausius-Clapeyron (Módulo 6):
- LaTeX: \mathcal{L}_{phys} = \lambda \cdot \text{Softplus}(\hat{y} - 4.0 \cdot TCWV)^2
- Texto puro: L_phys = λ · Softplus(y_hat - 4.0 · TCWV)²
